# WPS JSA 参考宏

本目录提供一套 WPS Office「JS 宏（JSA）」参考实现，功能与网页版/CLI 对齐，供需要在 WPS 内直接使用的场景参考。

## 文件

| 文件 | 说明 |
|---|---|
| `tag2bookmark_auto.js` | **主入口**：标签转书签自动化（唯一化 → 转书签 → 删除标签），推荐使用 |
| `tag2bookmark_only.js` | 仅转书签（不唯一化、不删除），适合分段核对的场景 |
| `unique_placeholders.js` | 仅占位符唯一化（重复 `${名}` → `${名_1}`、`${名_2}`…） |
| `delete_tags.js` | 仅删除 `${...}` 标签文本（保留书签） |
| `tag2bookmark_with_protection.js` | 带文档保护开合的封装：**密码在运行时弹窗输入**，代码中无任何硬编码密码 |

## 使用方式

1. 用 WPS 打开目标文档 →「开发工具」→「JS 宏」/「宏编辑器」；
2. 新建模块，把所需 `.js` 文件内容整体粘贴进去；
3. 运行对应函数（如 `标签转书签自动化()`）。

> 注：宏中的函数名为中文（如 `标签转书签自动化`），这是 WPS JSA 支持的中文标识符；也可自行改为英文函数名。

## 关于保护密码

`tag2bookmark_with_protection.js` 演示了「解除保护 → 处理 → 恢复保护」的流程：
- 文档受保护时，会通过 `InputBox` 请使用者输入保护密码；
- 密码只保存在内存变量中，不写入代码、不写入日志、不回显；
- 未受保护的文档不会索要密码。

该封装仅用于「需要自动在受保护文档上执行批量处理」的参考场景；如果只是普通处理，直接用 `tag2bookmark_auto.js` 即可（网页版/CLI 均不修改文档保护状态）。
