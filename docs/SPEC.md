# 处理口径（Specification）

本文档定义工具的处理规则，供二次开发与验收参考。

## 占位符定义

- 模式：`${...}`，`${` 与第一个 `}` 之间至少 1 个字符，且不能跨段落；
- 允许跨 run（文字格式切换常把 `${名称}` 拆成多段），按段落内文本流合并匹配；
- tab / 换行等控制字符会打断匹配（不跨过）。

## 三步处理

### 1. 唯一化（unique）

- **全文档连续计数**：正文与所有页眉/页脚共用同一计数器；
- 同名占位符按出现顺序改写：第 1 次保持 `${名}`，第 2 次 `${名_1}`，第 3 次 `${名_2}`…；
- 计数键为 trim 后的名称。

### 2. 转书签（bookmarks）

- 在每个占位符的**起始处**创建零宽书签（原文本删除后即为插入锚点）；
- 书签名清洗规则：
  1. 允许中文、字母、数字、下划线；其余字符替换为 `_`；
  2. 合并连续 `_`、去首尾 `_`；清空后用 `Placeholder` 兜底；
  3. 数字开头加 `B_` 前缀；
  4. 截断至 40 字符；
  5. 与已有书签重名时追加 `_1`、`_2` 递增后缀。

### 3. 删除标签（deleteTags）

- 删除 `${...}` 文本本身；书签为零宽 XML 元素，不受影响。

## 处理范围

正文（含表格、文本框内段落）+ 全部页眉/页脚部件。处理顺序：正文 → 页眉（文档引用序）→ 页脚（文档引用序），保证唯一化编号确定。

## 非改动项

- `settings.xml`（含 `documentProtection` 保护设置）原样保留；
- `.docm` 的宏工程（vbaProject.bin / JSA 工程等）字节级保留；
- 其他所有非文本部件原样回写。

## 保护与加密

- 限制编辑/窗体保护：**不读取、不校验、不修改**（输出保持原保护状态与密码）；
- 打开密码加密：不处理，检测到后提示用户先解锁另存；
- 参考宏 `macros/tag2bookmark_with_protection.js` 中的解锁密码由使用者运行时输入。

## 已知边界

- `.doc` 保真管道依赖外部文档引擎（见 README 平台差异表）；
- 网页版对 `.doc` 采用自研解析器（文本/表格/字体/字号/对齐/缩进/页面设置/表格列宽保留；图片、编号样式不保留）；
- 不支持老式 `.doc` 的加密变体与损坏文件。
